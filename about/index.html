关于

一个从 2024 年开始记录的地方，写代码，也写生活。

你好，我是 Ohh。这里是 ImsayingOhh， 名字取自我常挂在嘴边的一句 “I'm saying, ohh”。

站点的副标题是「椿萱并茂，棠棣同馨」， 它出自《诗经》，讲的是家人安康、兄弟和睦——也是我对生活最朴素的期待。

这里写什么

技术笔记占多数：前端、构建工具、一些踩过的坑。也会放生活碎片和读书时的摘抄。 文章不多，但都尽量写清楚“为什么”，而不只是“怎么做”。

这个站点怎么搭的

2024 年用 Hexo + Butterfly 起步，2026 年重做成现在的样子： Astro 5 静态生成、零客户端框架、内容用 Markdown 管理、评论挂在 GitHub Discussions 上。 没有服务器，没有数据库，所有页面在构建时就已生成好。
